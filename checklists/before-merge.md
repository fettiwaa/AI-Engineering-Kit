# Checklist: Before Merge

Follow `core/GIT.md` and `CONTRIBUTING.md`.

- [ ] At least one approvals from a maintainer.
- [ ] All CI checks green.
- [ ] No unresolved security findings (`prompts/security-audit.md`).
- [ ] No breaking changes without an ADR and version bump plan.
- [ ] CHANGELOG reflects the merged state.

> **Note:** Do **not** merge unless explicitly instructed.
