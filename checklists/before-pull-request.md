# Checklist: Before Pull Request

Follow `core/GIT.md` and `CONTRIBUTING.md`.

- [ ] Branch created from the correct base.
- [ ] Changes are small and focused.
- [ ] Tests added/updated; CI green.
- [ ] Documentation updated.
- [ ] CHANGELOG entry added under `[Unreleased]`.
- [ ] Link to any ADR if this changes architecture.
- [ ] PR description filled from `templates/pull-request.md`.

> **Note:** Do **not** push or open a PR unless explicitly instructed.
