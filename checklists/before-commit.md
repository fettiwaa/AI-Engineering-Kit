# Checklist: Before Commit

Follow `core/GIT.md` and `core/SECURITY.md`.

- [ ] Changes are staged selectively; only intended files.
- [ ] No secrets, tokens, or `.env` values present in diff.
- [ ] `git status` and `git diff` reviewed.
- [ ] Lint passes.
- [ ] Tests pass.
- [ ] `.gitignore` covers build outputs and dependencies.
- [ ] Commit message follows conventional format.

> **Note:** Do **not** run `git commit` unless explicitly instructed.
