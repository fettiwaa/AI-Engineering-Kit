# Checklist: Before Release

Follow `core/AI_WORKFLOW.md` §Production Readiness.

- [ ] CHANGELOG finalized for the version.
- [ ] All tests pass in CI.
- [ ] Security review completed (`checklists/security-review.md`).
- [ ] Performance review completed (`checklists/performance-review.md`).
- [ ] Accessibility review completed if UI is in scope.
- [ ] Migration plan in place for any DB changes.
- [ ] Rollback plan documented.

> **Note:** Do **not** publish a release unless explicitly instructed.
