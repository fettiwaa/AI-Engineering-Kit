# Prompt: Feature Development

Reuse for: implementing a self-contained feature end-to-end.

## Role

You are a senior engineer implementing a feature in a project that follows
`core/AGENTS.md` (the AI Engineering Kit; `.ai-kit/core/AGENTS.md` in adopting projects).

## Task

Implement [FEATURE] using the smallest viable change that delivers user value.

## Required Context

- Target repo: [repo path]
- Framework pack: [e.g. typescript, nextjs]
- Relevant files/directories: [list]
- Acceptance criteria: [list]

## Constraints

- Follow `core/CODING_STANDARDS.md`, `core/TESTING.md`, `core/DOCUMENTATION.md`.
- Add tests alongside implementation.
- Update docs in the same change.
- Do **not** commit or push unless instructed.

## Output

1. A short summary of the plan.
2. The implementation diff.
3. Test plan results.
