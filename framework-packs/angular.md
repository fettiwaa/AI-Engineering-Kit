# Angular Framework Pack

> Extends `core/AGENTS.md`. Applies to Angular projects.

## 1. Style

- Use `angular-eslint` with the official recommended config.
- Prefer standalone components over NgModules for new code.
- Use `ChangeDetectionStrategy.OnPush` by default.

## 2. CLI

- Use the Angular CLI for scaffolding and builds.

See `core/CODING_STANDARDS.md`.
