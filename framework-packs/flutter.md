# Flutter Framework Pack

> Extends `core/AGENTS.md`. Applies to Flutter projects.

## 1. Structure

- Follow feature-first folder structure.
- Prefer `const` constructors.
- Use `dart format` and `flutter analyze` in CI.

## 2. State

- Prefer `flutter_bloc` or `provider` for state management.
- Keep widgets stateless where possible.

See `core/CODING_STANDARDS.md`.
