# React Framework Pack

> Extends `core/AGENTS.md` and `framework-packs/typescript.md`. Applies to React projects.

## 1. Components

- Prefer function components and hooks.
- One default export per file; prefer named exports otherwise.
- Colocate styles and tests with components.

## 2. Hooks

- Follow the Rules of Hooks.
- Custom hooks are prefixed with `use`.

See `core/CODING_STANDARDS.md` §File Organization.
