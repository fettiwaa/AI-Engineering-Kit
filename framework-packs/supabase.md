# Supabase Framework Pack

> Extends `core/AGENTS.md`. Applies to Supabase projects.

## 1. Auth

- Secure sensitive operations in database functions with `auth.role()`.
- Use Row Level Security on every table.

## 2. Client

- Type the client from generated types.
- Use `supabase-js` with service_role only on the server.

See `core/DATABASE.md` and `core/SECURITY.md`.
