# Vue Framework Pack

> Extends `core/AGENTS.md`. Applies to Vue projects.

## 1. Style

- Prefer `<script setup>` with TypeScript.
- Use the Composition API.
- Scoped styles by default.

## 2. Components

- Kebab-case for custom elements, PascalCase for registered components in templates.

See `core/CODING_STANDARDS.md`.
