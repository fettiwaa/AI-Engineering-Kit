# Tailwind Framework Pack

> Extends `core/AGENTS.md`. Applies to Tailwind CSS projects.

## 1. Config

- Use Tailwind v3+ with JIT enabled.
- Extend the theme; do not override defaults lightly.

## 2. Usage

- Prefer composition over custom CSS.
- Use `tailwind.config.js` (or `.ts`) to safelist dynamic classes.

See `core/CODING_STANDARDS.md` §File Organization.
